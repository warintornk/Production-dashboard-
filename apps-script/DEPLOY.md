# นำการแก้ไขข้อมูลย้อนหลังขึ้นใช้งาน

ไฟล์ `Code.gs` เป็นฉบับแก้ไขของโค้ด Apps Script ที่ผู้ใช้ส่งมา ไม่ใช่ไฟล์เสริมให้วางซ้ำข้างโค้ดเดิม ห้ามมี `doGet` ซ้ำหลายไฟล์ในโปรเจกต์

## การตั้งค่าที่ต้องทราบ

รหัส Spreadsheet เดิมในโค้ดที่ส่งมาไม่ตรงกับลิงก์ Google Sheet ในแชต ฉบับนี้ตั้ง `SPREADSHEET_ID` เป็น `1mthoDraqJTpKQgTp89V7iiZyXTNjBkDloyC0YrT3E6s` ตามลิงก์ที่ผู้ใช้ระบุ รหัสนี้ใช้กับทั้งการอ่านและเมนูบันทึกเดิม ต้องยืนยันว่าเป็นชีตที่ใช้งานจริงก่อน Deploy ห้ามนำคีย์/token มาใส่ใน GitHub

## ขั้นตอนฝั่ง Google ที่เจ้าของบัญชีต้องทำ

1. เปิด Google Sheet เป้าหมาย → ส่วนขยาย → Apps Script เก็บสำเนาโค้ดเดิมไว้เพื่อย้อนกลับ
2. แทนที่ไฟล์เดิมที่ส่งมาให้ตรวจด้วยเนื้อหา `Code.gs` ฉบับนี้ แล้วบันทึก ไม่ต้องลบไฟล์อื่นหรือเปลี่ยนสิทธิ์แชร์ชีต
3. Deploy → Manage deployments → เลือก Web app ที่แดชบอร์ดใช้อยู่ → Edit → Version: New version → Deploy ใช้ deployment เดิมเพื่อคง URL เดิม และอนุญาตสิทธิ์อ่านชีตหาก Google ร้องขอ
4. เมื่อหน้าเว็บ `index.html` ฉบับแก้ไขขึ้นใช้งานแล้ว ให้กดโหลด/รีเฟรช เลือก Prepare และเดือน ก.ย. 2026 คลิกกราฟเดือนเพื่อดูรายวัน วันที่ 1 ต้องเป็น Input 209.8 / Output 150.9 จากนั้นลอง ก.ค. และ Assembly

อย่ากดเมนูบันทึก History เพื่อทดสอบการอ่าน: ไม่จำเป็นและอาจเขียนทับเดือนที่เคยบันทึก การแก้ไข `doGet` อ่าน History โดยตรง ไม่เปลี่ยน dropdown หรือเขียนชีต

## สิ่งที่แก้

- API รับ `month=MM-YYYY` หรือ `YYYY-MM` และอ่าน Daily Record เฉพาะเดือนตรงกัน มิฉะนั้นอ่าน archive แถว 42 เป็นต้นไป
- รองรับหัวบล็อก History แบบข้อความไทยและเซลล์ Date พร้อมปี ไม่อ่านซ้ำจาก display area แถว 9–39
- ส่ง `prepare.rows`, `assembly.rows`, `productionDailyHistory` และ `_meta.selectedMonth` ให้ตรงกับ frontend พร้อมคงชื่อ response เก่า
- Input = F (`actualHrs`), Output = E (`stdHrs`) ซึ่งเป็นชั่วโมงอยู่แล้ว ไม่หาร 60 และไม่แทนค่าว่างด้วย 0
- หน้าเว็บรับทุกเดือนที่ส่งมา แสดงยอดรายเดือน และโหลดรายละเอียดตามเดือน/ปีที่เลือก
- เมนูบันทึก/เลือก History รองรับ Date ใน J2/B4 และป้องกันการเขียนลงบล็อกที่เป็นคนละปี

## ทดสอบแล้ว / ยังไม่ได้ทดสอบ

ผ่าน unit และ browser integration ในเครื่อง รวมข้อมูลจริงจาก XLSX ของผู้ใช้: API → ตัวเลือกเดือน → กราฟรายเดือน → รายวัน ก.ย. → เปลี่ยนเป็น ก.ค. → เปลี่ยนเดือนจากเมนูด้านบน ไม่มี JavaScript errors และไม่มีการเขียนข้อมูลชีตในการทดสอบ

ยังไม่ได้รันบน Google Apps Script จริงหรือ Deploy ด้วยบัญชี Google เจ้าของชีต จึงยังไม่ถือว่าหน้าเว็บออนไลน์ได้รับการแก้ไข เมนูเขียน History/OT/Attendance ไม่ได้ถูกเรียกกับข้อมูลจริง การตอบกลับ `/version` และ POST actions ไม่ได้มี implementation อยู่ใน source ที่ส่งมา; ฉบับนี้ไม่เพิ่มการเขียน API ขึ้นเอง ไม่ควรแทนที่โค้ด Web app เวอร์ชันอื่นที่มี route เพิ่มเติมโดยไม่เทียบกับ source นั้นก่อน
